# 🌾 AgriSmart AI | Crop & Fertilizer Recommendation Engine

An AI-powered web application that recommends optimal crops and fertilizers based on soil nutrients and environmental conditions.

## ✨ Features
- **Crop Recommendation:** Suggests the most suitable crop based on soil Nitrogen (N), Phosphorus (P), Potassium (K), temperature, humidity, pH, and rainfall.
- **Fertilizer Recommendation:** Identifies nutrient deficiencies and recommends tailored fertilizers to improve soil health and crop yield.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** *(e.g., Streamlit / Flask, Scikit-learn, Pandas, NumPy)*
